# Backsound lo-fi overlay

Playlist loop yang diputar `overlay/js/music.js` (aktif via `?music=1`,
volume dari `config/game.json` -> `music.volume`, default 0.15 — sengaja
kecil supaya bunyi aksi tetap lebih terdengar).
